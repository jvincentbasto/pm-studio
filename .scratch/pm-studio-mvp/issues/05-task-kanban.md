# 05: Task Kanban

**What to build:** Workspace members can manage project tasks on a Kanban board, assign task owners, and track due dates and progress.

**Blocked by:** 03: Workspace invitations and member access; 04: Project management.

**Status:** ready-for-agent

- [ ] Members can create, view, edit, and delete tasks in a project.
- [ ] Tasks can be assigned to workspace members and given an optional due date.
- [ ] Tasks move among Backlog, Todo, In Progress, and Done.
- [ ] The board shows each task under its current status and preserves status changes.
- [ ] Invalid assignments and cross-workspace task access are rejected.
