# 04: Project management

**What to build:** Workspace members can manage projects in their workspace and see the correct project list.

**Blocked by:** 01: Email/password accounts and workspace creation.

**Status:** ready-for-human

- [x] Members can create, view, edit, and delete projects within their workspace.
- [x] Project data is isolated by workspace, with server-side authorization on every operation.
- [x] Members see a useful empty state when their workspace has no projects.
