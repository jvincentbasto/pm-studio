# 02: Google and GitHub sign-in

**What to build:** A visitor can sign in or register with Google or GitHub and safely link that identity to an existing account.

**Blocked by:** 01: Email/password accounts and workspace creation.

**Status:** ready-for-human

- [x] A visitor can sign in or register using Google.
- [x] A visitor can sign in or register using GitHub.
- [x] Verified provider identities link safely to the same user's existing account.
- [x] Conflicting or unverified identities cannot take over an existing account.
- [x] Backend and browser tests cover new identities, existing identities, and conflicts.
